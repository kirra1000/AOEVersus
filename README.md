# AOEVersus

Program that compares 2 players accounts, displays all there games with a win/loss ratio at the bottom. Supports multiple/smurf accounts.
Has some popular pros/streamers account when clicking on the player dropdown. Provides a AoE 4 Worlds gamelink for both sides. If the link doesn't work, the account is private.

Uses the [Aoe 4 Worlds API](https://aoe4world.com/api) for game calls.

Use Angular version 18.2.6.

## Installing and Running

Install Angular and run `npm i` to install dependencies.
Run `ng build` to build the project.
Run `ng serve`, navigate to `http://localhost:4200/`.
